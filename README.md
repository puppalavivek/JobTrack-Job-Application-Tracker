JobTrack – Job Application Tracker

JobTrack is a Flask-based web application that helps users organize and manage their job applications in one place.

Features

* User registration and login
* Secure password hashing
* Add, edit, view, and delete job applications
* Track application statuses (Applied, Interview, Selected, Rejected)
* Interview date and time management
* Calendar view for interviews
* Upcoming interview reminders
* Dashboard with application statistics
* Application status chart
* Search and filter applications
* Export application data to CSV
* User profile and profile picture management

Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript
* Chart.js

Project Purpose

This project was developed to practice Python web development, database management, user authentication, and frontend design.

Future Improvements
